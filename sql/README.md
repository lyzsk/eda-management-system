# EDA Management System · PostgreSQL 建表脚本

目标数据库：PostgreSQL 17.x。默认 schema：`ems`。应用账号：`ems/ems`（开发环境，生产必须改）。

## 目录

| 文件 | 说明 |
|:--|:--|
| `create_database.sql` | 用 postgres 超级用户创建/接管 `ems` 数据库和 `ems` 角色；库已存在时把 owner 改为 `ems` |
| `schema.sql` | 创建 `ems` schema |
| `sys_user.sql` | 用户表 |
| `sys_role.sql` | 角色表 |
| `sys_menu.sql` | 菜单表 |
| `sys_dept.sql` | 部门表 |
| `sys_dict_type.sql` | 字典类型表 |
| `sys_dict_data.sql` | 字典数据表 |
| `eda_tool.sql` | EDA 工具清单表 |
| `eda_tool_alter.sql` | `eda_tool` 增加 `server_id`（关联服务器，幂等） |
| `eda_server.sql` | 服务器表（SSH 目标、加密凭据） |
| `eda_script.sql` | EDA 服务操作脚本表（启动/停止/重启/状态/任务） |
| `eda_script_run.sql` | 脚本执行历史表 |
| `seed.sql` | 基础数据：公司（id=0）、数据中心（parent_id=0）、管理员、角色、菜单、字典、示例 EDA 工具 |
| `init.sql` | 幂等统一初始化脚本（schema + 全部表 + seed） |

## 首次初始化

> 如果 `ems` 数据库已经用 pgAdmin/其他方式建好了，第一步的脚本会跳过建库、创建 `ems` 角色并把数据库 owner 改为 `ems`，然后第二步用 `ems` 账号建表即可。

### 1. 创建角色和数据库（postgres 超级用户）

```bash
cd /c/Users/admin/dev/eda-management-system
PGPASSWORD='<postgres密码>' "/c/Program Files/PostgreSQL/17/bin/psql.exe" \
  -h 127.0.0.1 -U postgres -d postgres -v ON_ERROR_STOP=1 \
  -f sql/create_database.sql
```

### 2. 建表 + 基础数据（ems 账号）

```bash
PGPASSWORD='ems' "/c/Program Files/PostgreSQL/17/bin/psql.exe" \
  -h 127.0.0.1 -U ems -d ems -v ON_ERROR_STOP=1 \
  -f sql/init.sql
```

### 3. 验收

```bash
PGPASSWORD='ems' "/c/Program Files/PostgreSQL/17/bin/psql.exe" \
  -h 127.0.0.1 -U ems -d ems -c "\dt ems.*"

PGPASSWORD='ems' "/c/Program Files/PostgreSQL/17/bin/psql.exe" \
  -h 127.0.0.1 -U ems -d ems -c "select id, parent_id, dept_code, dept_name from ems.sys_dept order by id;"

PGPASSWORD='ems' "/c/Program Files/PostgreSQL/17/bin/psql.exe" \
  -h 127.0.0.1 -U ems -d ems -c "select id, username, real_name, status from ems.sys_user;"
```

期望：7 张表；`sys_dept` 两行（公司 id=0、数据中心 id=1）；`admin` 一行且 `dept_id=1`。

## 默认账号

- 用户名：`admin`
- 密码：`admin123`
- 密码为 BCrypt 哈希，可直接在 `seed.sql` 中看到。

## 约定

- 主键 `BIGINT GENERATED BY DEFAULT AS IDENTITY`，由数据库自增；MyBatis-Plus 使用 `IdType.AUTO`。
- `status`：1 启用/在线，0 停用/离线。
- 时间 `TIMESTAMP(6)`，Java `LocalDateTime`。
- 表之间不加数据库外键，应用层校验。
- `init.sql` 幂等，不执行 DROP/TRUNCATE，可重复运行。
